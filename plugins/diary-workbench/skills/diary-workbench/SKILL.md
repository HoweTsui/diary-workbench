# 日记工作台

从本文件位置向上两层定位插件根目录，不使用开发者机器上的绝对路径。

- 用 Node.js 22+ 执行插件内 `scripts/start.mjs`，保持服务运行。初次启动安装锁定的工作台依赖；缺少运行环境时明确报告，不声称已经启动。
- 默认端口 8185，与开发者个人工作台隔离。使用启动程序打印的实际地址，通过 Codex 的 `open_in_codex` 浏览器面板打开。若工具不可用，提供本地地址，不声称打开了面板。
- 页面有填写、预览、归档和原阅读器入口。对话任务与页面采用同一数据；使用页面已注册的 Site Tools 查询状态或提交生成，不另写一个工程。
- 提交生成只创建等待接手的私有任务，不启动隐藏后台聊天。用 Site Tool `get_diary_generation_handoff` 读取任务指令，或读取用户粘贴的指令。在当前聊天执行指令里的 `chat-task.mjs ... take`，从指定工作区读取 `generation-instructions.md` 和 input.json。按完整日记 Skill 调用内置 Imagegen、合成并实际查看最终图；写 result.json 后执行指令里的 complete 命令。页面自动读取结果，只有通过真实调用、看图及内容检查才展示成品。失败时执行 fail，不能把文字回复或普通文件冒充生图完成。用户仍需在页面确认归档。
- 生成必须完整读取同插件 `skills/cartoon-diary-journal/SKILL.md` 及其指定规则。默认库无角色、无旧日记。不得将风格参考中的角色当成用户身份；根据本次输入补充真实角色来源。
- 仅实际生成完成的海报进入预览。用户确认海报与实际新增身份版本之后才归档。内部画风检查不展示为用户审批页面。
- 连接既有笔记库前先核实用户给出的目录和原阅读器格式。不要搜索并默认连接某个个人 Wiki。不要将空白默认库误称为已同步笔记工具。
- 历史画风转换只在用户另行请求后执行；新增版本，不覆盖旧海报、不改变原文及日记结构，也不自动替换原嵌图。

配置、草稿、照片、任务结果为用户私有数据，不在插件源代码或发布包内。
