# 日记版式

版式以style-system.md为准。全部场景照片的主要内容整合进同一张3:4海报的最多5行，不因超过5张而自动舍弃来源。用 posterRows 分开记录行数与插画数；每行可有多个相关独立插画，同一事件的多张照片也可共用一个插画。按明确时间从上到下阅读，未知时沿用上传顺序。先简化非必要背景、合并重复动作并保持留白；不虚构不同事件同时发生，不缩字、不裁人物、不生成漫画框。细则见 photo-integration.md。没有场景照片时继续按文字选择1–5场；单事件不补造填充人物或动作。

新海报3:4；固定日期标题与右侧备注层级。原文不印在图中；文字超预算时由Agent重新撰写，不截断、不缩字。历史9:16海报仍由日记本contain完整显示。

角色卡与表情动作测试使用完整白底构图，不强制附加日记日期、横线或右侧栏。
