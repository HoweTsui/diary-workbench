# 视觉规范入口

默认画风唯一以已确认的 assets/style-reference/style-lock-v1/master-approved-v2.png 和 style-contract.md 为准。生成器对所有 brief 自动附上母版。调用方式、角色校准和单场景合成见 style-lock.md；旧 reference-manifest.json 只保留历史用途，不再作为新任务的生成包。

数值由 geometry.json 注入，以角色头宽 H 为单位；肢体的 stroke 是单根线宽，innerGap 是净白缝，outerWidth=2*stroke+innerGap。每段裸露肢体只有两条外轮廓，内部白色，不补中线；动作只改变走向，不相对上一张图反复缩短或加粗。新角色沿用母版画法并保留用户身份，不复制示例身份。

armWidth、legWidth必须同时等于outerWidth，不再允许臂腿各自偏差10%；同一角色按同一个H比较裸露上臂/前臂/大腿/小腿直段，不能每段另选单位。弯肘、屈膝、坐姿和抱宠物同样适用；袖口、裤裙宽度不代替裸露肢体宽度。单根线宽恒定，开放端点为半圆封口，不渐细；完整线条、主色块和简约道具规则唯一由 style-contract.md 注入实际请求。

手臂、腿部、手掌和鞋的侧向关系另见 `assets/style-reference/character-extension-v1/limb-hand-foot-proportions-v2.png`，须与 `appearance-unified-v5.png` 成对使用：头身朝侧面，近侧手臂可见、远侧通常遮挡，近远腿前后错位；只收窄四肢双线之间的白缝，不改变单根描边粗细；所有开放端点只能圆头、不得尖收笔。手掌宽度和侧向椭圆鞋长度仍按 canonical geometry，禁止随四肢一起缩小。该图不替代已确认人物参考、身份图或表情参考。

当前 1536×1024 四肢参考图的裸露手臂实测外宽为成人约 24px、儿童约 21px；这次反馈优先于此前 28/24px 的较粗目标。换画布按人物比例缩放，不把像素值机械套用到所有角色。以**当前两张图**共同核对臂腿与手掌/鞋的相对比例，不回退到过粗版本。`geometry.json` 的 `stroke` 保持不变，`armWidth`/`legWidth` 是头宽单位的设计基线；裸露肢体仍须双线留白。若生成图明显粗于当前参考，判定失败并重生，不通过更改全身描边粗细来掩盖。

所有文字用随包悠哉字体。日记为3:4白底，14–18条浅青横线由本地绘制，横线贯穿右侧；顶部日期、下一行标题，右侧20–25%为备注，插画不越界。黑色实墨目标≤20%、硬上限30%；除浅青横线外无装饰色。3D翻页只允许干净、轻微的中性灰阴影。

同一20%/30%黑墨指标也逐角色检查，不增加未经用户确定的最低百分比；人物必须有一处主要纯黑区域，不以眼珠、张嘴或细小标志充数。角色检查排除外围留白、背景、道具和其他角色；独立透明角色图可用 check_poster_ink.py --character 做技术检查，场景内人物另做逐个目视核对，不假称脚本能自动分割。只通过整页比例不能通过角色检查。

保留平滑抗锯齿，不做最近邻放大或硬边量化。每篇日记保留完整原文；全部场景照片主要内容整合进同页最多5行，不只选5张。相同事件融合，不同动作逐次生成独立插画再按行留白合成，插画数与行数分开，不能让模型画条带小分镜。没有场景照片时按文字选择1–5场。图像模型不画文字、纸张横线或矩形背景；完整等比放置。内容覆盖和附件打包见 photo-integration.md。
