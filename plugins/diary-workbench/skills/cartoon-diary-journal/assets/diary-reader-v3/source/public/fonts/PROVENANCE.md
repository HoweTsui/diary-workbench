# Bundled handwriting font

悠哉 / Yozai. Source: https://github.com/lxgw/yozai-font, release v0.868.

The bundled Regular and Medium TrueType files are local-only assets under SIL Open Font License 1.1; the complete license is included as `Yozai-OFL.txt`. CSS and Canvas both use the `Yozai` family and wait for it before rendering text.
