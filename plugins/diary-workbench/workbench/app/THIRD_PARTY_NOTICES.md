# Amicro activity heatmap

`src/MonoActivityHeatmap.jsx` adapts the 20-week, seven-day square grid and blue accent of [MonoActivityHeatmap](https://github.com/Subhan-code/Amicro--Micro-transitions-/blob/main/src/components/mono-charts/MonoActivityHeatmap.tsx).

Changes: light-only design tokens, real diary illustration data instead of random demo data, accurate month/date labels, keyboard-accessible buttons, selected-date navigation, no Tailwind/Motion runtime dependency.
