# 隐私与数据

- 默认目录为空，没有真实日记、原图、角色身份、账号凭据或个人笔记库路径。
- 工作台仅监听本机地址。草稿、上传的原图和生成任务保存在本机浏览器存储与用户数据目录中；不是匿名遥测服务。
- 图片生成时，用户提供的事件、照片和必要角色参考会交给当前 Codex 聊天及其图片生成能力处理，不能将“本地工作台”理解成模型也完全离线运行。
- 默认数据目录为 `~/.local/share/diary-workbench-default`；Windows 优先使用 `LOCALAPPDATA`。可以用 `DIARY_WORKBENCH_DATA` 更改，避免放入公开仓库。
- 连接 Obsidian 必须由用户指定，不能自行寻找某个 Wiki。只有明确确认后的成品才归档；旧原图、旧海报及正文不因安装插件而被改写。
- 提交 Issue 请使用虚构内容；不要附上 `.local`、workspace.json、任务日志、个人照片、浏览器存储或账号信息。
- 通用风格参考仅定义画风，不代表任何新用户或其家人、宠物。
